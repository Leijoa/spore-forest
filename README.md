# 🍄 孢子森林

一款可以在手機與電腦瀏覽器直接玩的蘑菇增量遊戲。點大蘑菇收集孢子，購買菌群自動產出，把小香菇養成小屋、村莊、聚落，最後蓋出蘑菇城堡。

## 遊玩方式
- 點擊蘑菇收集孢子，連擊與暴擊會提高收益
- 在「菌群」「強化」分頁花孢子升級
- 湊齊多種菌群，村莊會一路進化到城堡，各階段有專屬活動（舞會、營火、市集、煙火、遊行）
- 「孢子雨」可轉生，換取永久加成

## 存檔
進度存在瀏覽器的 localStorage，只會留在**同一個瀏覽器、同一個裝置**。換裝置或清除瀏覽器資料前，請先用遊戲底部的「匯出存檔碼」備份。

## 本機執行
單一 `index.html` 檔案，不需要建置，直接用瀏覽器開啟即可。
