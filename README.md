# 🍄 孢子森林

一款可以在手機與電腦瀏覽器直接玩的蘑菇增量遊戲。點大蘑菇收集孢子，購買菌群自動產出，把小香菇養成小屋、村莊、聚落，最後蓋出蘑菇城堡。

## 遊玩方式
- 點擊蘑菇收集孢子，連擊與暴擊會提高收益
- 在「菌群」「強化」分頁花孢子升級
- 湊齊多種菌群，村莊會一路進化到城堡，各階段有專屬活動（舞會、營火、市集、煙火、遊行）
- 「孢子雨」可轉生，換取永久加成

## 存檔
進度存在瀏覽器的 localStorage，只會留在**同一個瀏覽器、同一個裝置**。換裝置或清除瀏覽器資料前，請先用遊戲底部的「匯出存檔碼」備份。

## 本機執行
單一 `index.html` 檔案，不需要建置，直接用瀏覽器開啟即可。

## 菇菇圖鑑
「圖鑑」分頁可查看苔苔、桃桃、慢慢的大圖、個性與解鎖條件。點大圖可以打招呼；遇見後收藏跨轉生保留。圖鑑中可查看 11 個自動成就，分為自然成長與刻意挑戰。無需接受或領獎，不在主場景放任務卡；回憶與貼紙直接收藏，跨轉生保留。11 個成就各有專屬圖案，可在圖鑑的貼紙收藏冊點選放大；未解鎖時顯示剪影與條件。

## 圖鑑檢查
安裝 Playwright 並備有 Microsoft Edge 後，執行 `node tests/album.cjs`。也可透過 `PLAYWRIGHT_MODULE` 指定 Playwright 模組位置。檢查包括解鎖、互動、舊存檔、轉生保留、刪除與壞檔保護。

成就檢查：`node tests/wishes.cjs`（沿用原測試檔名），涵蓋自然成長、刻意挑戰、無干擾收藏、舊願望遷移、完成去重與轉生相容。
