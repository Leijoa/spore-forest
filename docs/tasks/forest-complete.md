## 決策完整規格

### 1. 居民分工

新增「森林」分頁，主要操作都在此，不在採集舞台放卡片。兩個工作槽，各可選空位或已解鎖 moss/peach/elder；同人不可兩槽。每槽工作選「採集幫手」或「菌群照料」。採集幫手每人讓基礎點擊量 +15%；照料每人讓基礎自動產出 +10%。乘區相加後套一次，最多 1.30／1.20。作用於既有升級／種子計算後、慶典／連擊前；不要把點擊衍生自動部分再次加兩遍。精確定義寫規格並讓 UI 預覽與權威函式一致。離線使用照料加成，不補限時慶典、buff、連擊。工作在轉生保留（永久身份已認識），無需每輪重新操作。無收費、無工作條件、可即時換，不增採集獎励按鈕。

Canvas 工作角色用既有居民造型，持小籃子採集／澆水壺照料，慢慢可慢步照料；明確區分兩种动作。可增加小型工作專屬演员，控制固定最多兩位，不能污染原居民上限／解鎖。

### 2. 慶典準備

森林分頁選「下一場」：自動或當輪已解鎖的 EVENTS，不能挑未解鎖。準備可選「隨意聚聚」(原效果)、 「花環」(本場持續時間 +8秒)、「野餐籃」(本場活動乘數 1.65，原1.5)。無費用、無倒數期限、無選任務。下一次活動開始拍快照，開始後改設定只能影響下場。消耗後下一場回自動、準備回隨意，界面正確显示本場與下場。轉生清除下場安排與目前活動／連擊／臨時buff，避免重生沿用本輪暫態；收藏與永久配置保留。現有隨機活動保持，減少動態同樣有計時／經濟結果。開始活動舞台演出加入花環或野餐道具，結束移除。

### 3. 三格裝飾

固定左／中／右槽，下拉選無／長椅／閱讀燈／信箱，同款可重複。全三款無貨幣解鎖，穩定條件：長椅認識苔苔、燈認識桃桃、信箱認識慢慢；解鎖後永久保存。Canvas 每件有小菇實際坐下／讀書／拿信演出；不能只換場景顏色。裝飾不給產出倍率，可任意替換，轉生保留。沒解鎖顯示名字／條件、不洩漏已解鎖假象。

### 4. 主題森林

三款：原版「星光森林」預設；「晨露花園」認識全三位居民；「月光書林」完成 story 自動成就。解鎖永久，設定轉生保留；舞台背景＋地面／粒子各有辨識差異，尊重減少動態。每款附一段小故事，森林分頁看得見，不給倍率。不得動 UI 文字對比／點擊區，不能只在分頁宣稱已換主題。

### 5. 稀有訪客

三位可辨識原生插圖＋名字＋完整互動回應＋永久故事：
- 「露露」戴葉帽小旅人：放長椅且認識苔苔。
- 「小墨」抱書紫菇：使用月光書林且放閱讀燈。
- 「郵郵」背郵袋橙菇：放信箱且完成至少一種慶典。

條件滿足立即自動加入訪客圖鑑，无随机、現實節日、任務接受、領獎或popups。這是配置探索，不增加成就或貼紙數目。圖鑑新增訪客收藏區，未見輪廓＋明確條件，已見能看圖與點擊回應；點擊不獎孢子、適量節流／鍵盤可用。舞台適量一位訪客轮替演出：露露休息、小墨讀書、郵郵送信。故事／訪客身份永久保存，轉生配置已保留可繼續演出。不能用相同三菇emoji充當專屬外觀。
